# 竞品图 #2：美国 250 周年国庆纪念拼块毯
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 规则卡 DRAFT-002

**规则名称**：国旗/国庆拼块徽章规则
**复用等级**：B 级（强依赖特定国家+特定年份事件，但拼块构图模式可复用）

### 第 1 层｜商业层
- **目标人群**：美国爱国消费者、军人家庭、退伍军人、国庆节礼物
- **使用场景**：美国独立日 7.4、美国 250 周年（2026 特定事件）、退伍军人纪念
- **购买动机**：表达爱国情怀，纪念国家大事件，个性化名字=专属纪念品
- **核心情绪**：自豪、庄重、复古、纪念感、荣耀
- **价格敏感度**：中（纪念品消费，限时热度）

### 第 2 层｜视觉结构层
- **构图公式**：九宫格/多宫格拼块布局（quilting patchwork style），每个格子一个独立图案
- **必备元素**：
  | 槽位 | 内容 | 位置 |
  |---|---|---|
  | 主题徽章 | 国旗盾牌、大星、椭圆旗纹 | 上排三个格子 |
  | 名字 | 个性化名字（WILLIAM） | 中排左格 |
  | 核心文案 | "250th Anniversary United States" | 中排中格（最大的格） |
  | 节日元素 | 烟花 | 中排右格 |
  | 标志性图案 | 飘扬国旗、自由女神像、鹰徽 | 下排三个格子 |
  | 年份 | 2026 | 下排右格 |
  | 分隔条 | 红白条纹+星星角标 | 格子之间 |
- **风格**：复古美式拼布（vintage Americana quilting），做旧质感，像缝制的被子
- **色彩情绪**：红+深蓝+米白+金棕，复古庄重
- **文字层级**：核心文案最大 > 名字 > 年份

### 第 3 层｜可变边界层
**可替换的**：
| 维度 | 原始 | 可替换成 |
|---|---|---|
| 国家 | 美国 | 其他国家（英国/加拿大/澳大利亚/法国等） |
| 事件 | 250 周年国庆 | 其他纪念日（建军节/独立日/国王加冕等） |
| 徽章图案 | 国旗/鹰/自由女神 | 对应国家的标志性图案 |
| 颜色 | 红蓝白 | 对应国家的国旗色 |
| 拼块风格 | 复古拼布 | 现代几何拼块 / 邮票风格 / 军事臂章风格 |

**不能换的**：
- 九宫格/多宫格拼块布局（这是这张图的核心视觉识别）
- 名字个性化
- 庄重纪念感（不能变成搞笑风）
- 复古质感（不能变成塑料感/科技感）

### 第 4 层｜产品适配
- **毛毯**：当前图直接适用，拼块风天然适合大面积毛毯
- **相框/挂画**：缩减到 4 格或 6 格，保留核心徽章
- **衣服**：只取一个核心徽章（如鹰+国旗），不做满版拼块
- **马克杯**：横向排 3-4 个徽章即可

### 第 5 层｜数据验证
- 季节依赖：**高**（主要在国庆前后卖，2026 年是 250 周年热点年）
- IP 依赖：无（国旗/自由女神是公共领域）
- 复用等级：**B 级**——拼块构图模式可复用，但内容强绑定美国+250 周年

---

## 改款推荐

**推荐方向**：保留"拼块徽章+名字定制+纪念感"的构图模式，换成一个不依赖特定年份的主题，提升复用性。

**具体方案**：改成 **家族传承/家庭纪念拼块毯**
- 九宫格 → 保留
- 国旗徽章 → 换成家庭象征图案（家庭树、心形、房子、手印、宠物、星座）
- "250th Anniversary" → 换成 "The [Family Name] Family, Est. [Year]"
- 红蓝白 → 换成暖色系（棕+深绿+米白+金色），复古家庭相册感
- 名字 → 保留（家庭姓氏或家庭成员名字）
- 复古拼布质感 → 保留

**改款说明**：同一条规则从 B 级（绑定特定事件）升级到 A 级（家庭纪念全年可卖）。

# 竞品图 #3：骷髅手比心情侣毯
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 规则卡 DRAFT-003

**规则名称**：暗黑/哥特情侣+趣味文案+名字定制规则
**复用等级**：A 级（情侣定制全年可卖，暗黑哥特是稳定亚文化，可跨产品）

### 第 1 层｜商业层
- **目标人群**：年轻情侣（偏另类/哥特/朋克/暗黑审美）、闺蜜送礼
- **使用场景**：情人节、恋爱纪念日、结婚纪念日、生日礼物、日常秀恩爱
- **购买动机**："我们不是普通情侣，我们有点怪但很甜"——用暗黑元素表达甜蜜，反差萌
- **核心情绪**：反差萌、叛逆甜蜜、幽默、个性、"我们很特别"
- **价格敏感度**：中（礼物型消费+个性化溢价）

### 第 2 层｜视觉结构层
- **构图公式**：中央大型标志性手势/符号 + 内部文字区 + 散落装饰元素满铺背景
- **必备元素**：
  | 槽位 | 内容 | 位置 |
  |---|---|---|
  | 中央主视觉 | 两只骷髅手比心形成爱心形状 | 正中央，最大元素 |
  | 名字 | 两个人名字（William & Sophia） | 爱心内部上方 |
  | 趣味文案 | "You're My Favorite Weirdo" | 爱心内部中间 |
  | 纪念日期 | EST. 12-24-2010 | 爱心内部底部 |
  | 背景装饰 | 大小不一的红色爱心散落满铺 | 上下两端散落 |
  | 背景底色 | 纯黑色 | 整个画面 |
- **风格**：简洁图形化，骷髅手是线描白色，爱心是平涂红色，强对比
- **色彩情绪**：黑+白+红，暗黑但浪漫，高对比度
- **文字层级**：名字最大 > 趣味文案 > 日期最小

### 第 3 层｜可变边界层
**可替换的**：
| 维度 | 原始 | 可替换成 |
|---|---|---|
| 中央手势/符号 | 骷髅手比心 | 骷髅手比 rock 手势、两个骷髅头接吻、骷髅手牵手、黑猫互蹭、蛇缠绕心形 |
| 散落装饰 | 红色爱心 | 骷髅小花、蝙蝠、星星、蜘蛛网+心、黑玫瑰花瓣 |
| 趣味文案 | "You're My Favorite Weirdo" | "Partners in Crime" / "Til Death Do Us Part" / "Two Weirdos in Love" / "My Person" |
| 色彩方案 | 黑+白+红 | 黑+白+紫（哥特）、黑+金（奢华暗黑）、黑+绿（毒药风） |
| 节日变体 | 通用 | 万圣节（加南瓜蝙蝠）、情人节（加更多心）、圣诞暗黑版（骷髅圣诞帽） |

**不能换的**：
- 暗黑/哥特的整体调性（换成明亮可爱就不是这条规则了）
- 两个人名字的个性化（核心购买动机）
- 纪念日期
- 趣味/叛逆感的文案（如果文案太正经就失去反差萌）
- 黑色底（暗黑风的基础）

### 第 4 层｜产品适配
- **毛毯**：当前图直接适用，黑底+简单图形在毛毯上效果好
- **衣服（T恤/卫衣）**：非常适合，暗黑风本来就是服装强项。可以只保留中央手势+名字，去掉散落爱心
- **马克杯**：骷髅手比心做成杯面主视觉，名字在杯背
- **手机壳**：骷髅手比心缩小居中，减少散落装饰

### 第 5 层｜数据验证
- 季节依赖：**低**（情人节有高峰，但纪念日/生日全年有需求）
- IP 依赖：**无**
- 复用等级：**A 级**——暗黑情侣是稳定亚文化市场，跨产品（毯+衣+杯+壳）

---

## 改款推荐

**推荐方向**：保留"暗黑哥特+情侣名字+趣味文案+黑底高对比"的规则，换中央主视觉和装饰元素。

**具体方案**：改成 **两只黑猫互蹭 + 月亮 + 暗黑浪漫**
- 骷髅手比心 → 两只黑猫头互蹭，形成心形轮廓
- 红色爱心散落 → 月亮+星星+小猫爪印散落
- "You're My Favorite Weirdo" → "Meow & Forever"
- 黑+白+红 → 黑+白+紫+金月亮（哥特浪漫感）
- 风格不变：简洁图形，高对比

**改款理由**：猫是互联网第一宠物 + 暗黑哥特 + 情侣 = 受众交集大，且完全避开了骷髅元素（部分平台对骷髅有限制）。

# 竞品图 #4：Best Mom Ever 照片拼贴 Bootleg 风
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 规则卡 DRAFT-004

**规则名称**：Bootleg 复古 T恤风照片拼贴规则
**复用等级**：A 级（构图模式强，跨节日跨人群，但依赖用户照片上传）

### 第 1 层｜商业层
- **目标人群**：子女（送妈妈/爸爸/奶奶）、配偶互赠
- **使用场景**：母亲节、父亲节、生日、圣诞节
- **购买动机**："用我们的照片做一份独一无二的纪念品"——照片定制=最高级别的个性化
- **核心情绪**：搞笑、潮酷、反差（复古 rap tee 风格 + 温情家庭照 = 意想不到的组合）、致敬感
- **价格敏感度**：中高（照片定制溢价高，买家不比价）

### 第 2 层｜视觉结构层
- **构图公式**：顶部大标题 + 中央大主图（照片）+ 周围环绕小照片 + 闪电/光效背景
- **必备元素**：
  | 槽位 | 内容 | 位置 |
  |---|---|---|
  | 大标题 | "BEST MOM Ever"（金属感/闪光3D文字） | 顶部，最醒目 |
  | 中央主照片 | 妈妈和孩子的合影（最大） | 正中央 |
  | 环绕小照片 | 5-6 张不同角度/时期的家庭照 | 围绕中央主照片 |
  | 光效背景 | 紫色闪电/光芒/星光效果 | 整个背景 |
  | 底色 | 黑色/深色 | 背景 |
- **风格**：90 年代 Bootleg rap T恤风格（vintage bootleg tee），金属感文字，夸张光效，照片做圆形/椭圆裁切
- **色彩情绪**：黑+紫+粉+金属闪光，夜店/演唱会海报感
- **文字层级**：大标题最醒目（3D金属感）> 无其他文字

### 第 3 层｜可变边界层
**可替换的**：
| 维度 | 原始 | 可替换成 |
|---|---|---|
| 主角 | MOM | DAD / GRANDMA / GRANDPA / WIFE / HUSBAND / SISTER / BROTHER / TEACHER |
| 文案 | "BEST MOM Ever" | "BEST DAD Ever" / "World's Greatest Grandma" / "Legend Since 1985" |
| 照片数量 | 1 大 + 5 小 | 灵活调整（3 张/7 张/9 张） |
| 光效颜色 | 紫色闪电 | 蓝色闪电 / 红色火焰 / 金色光芒 / 绿色极光 |
| 节日变体 | 母亲节 | 父亲节、生日（"Legend Since [年份]"）、退休纪念 |

**不能换的**：
- Bootleg/复古 rap tee 的视觉风格（这是这条规则的灵魂，换了就不是这款了）
- 照片拼贴的个性化核心（没有照片这款就不成立）
- 黑底/深色底 + 夸张光效（这是 bootleg 风的基础）
- 3D 金属感大标题（标志性视觉元素）

### 第 4 层｜产品适配
- **毛毯**：当前图适用。注意照片要高清，印大了不能糊
- **衣服（T恤/卫衣）**：天然适配！Bootleg 风本来就是 T恤起源的，缩小照片数量
- **海报/挂画**：非常适合，直接当房间装饰
- **马克杯**：缩减到 1 张照片 + 标题

### 第 5 层｜数据验证
- 季节依赖：**中**（母亲节/父亲节高峰，但生日全年有）
- IP 依赖：**无**
- 特殊依赖：**依赖用户上传照片**——这是核心卖点，也是生产限制
- 复用等级：**A 级**——跨人群（妈妈/爸爸/奶奶/闺蜜），跨产品（毯+衣+海报）

---

## 改款推荐

**推荐方向**：保留"Bootleg rap tee 风格+照片拼贴+3D金属标题"的构图模式，换主题人群。

**具体方案**：改成 **BEST DAD Ever 父亲节版**
- MOM → DAD
- 紫色闪电 → 蓝色闪电+金色光芒（更有力量感）
- "BEST MOM Ever" → "BEST DAD Ever" 或 "THE LEGEND"
- 照片内容 → 爸爸和孩子们（提示词描述场景即可，实际使用时放用户照片）
- 风格完全不变：bootleg rap tee 黑底闪电 3D 金属字

**重要说明**：这条规则的核心是**照片定制**，AI 生图不能替代真实照片。所以提示词的目标是**生成"无照片的模板/背景"**，照片区域留空，后期用户上传照片合成。

## 规则卡 DRAFT-005

**规则名称**：家庭花园/每人一花+名字规则
**复用等级**：**S 级**（跨产品、跨人群、跨节日、全年通用、高度可个性化）

### 第 1 层｜商业层
- **目标人群**：子女送妈妈/奶奶、配偶互赠、家庭成员互赠
- **使用场景**：母亲节、奶奶生日、家庭聚会礼物、乔迁礼物、圣诞节
- **购买动机**："每个孩子一朵花，代表我们在妈妈的花园里成长"——每个家庭成员都有专属位置，强情感连接+高度个性化（名字数量可变）
- **核心情绪**：温暖、归属感、成长、感恩、家庭纽带、自然清新
- **价格敏感度**：中高（家庭个性化+情感价值高，不比价）

### 第 2 层｜视觉结构层
- **构图公式**：顶部标题区 + 下方多株花朵并排陈列（每株花代表一个家庭成员）
- **必备元素**：
  | 槽位 | 内容 | 位置 |
  |---|---|---|
  | 主标题 | "Mom's Garden" | 顶部居中，最大文字 |
  | 副标题 | "Where Love Grows" | 主标题下方 |
  | 装饰 | 蝴蝶（2-5只不等） | 标题周围、花朵间 |
  | 花朵 1-N | 每人一株独立花朵（不同种类），花下有该人名字 | 中下部，等间距排列，可分多排 |
  | 名字 | 每株花下方的手写体名字 | 花朵正下方 |
  | 背景 | 纯白色 | 整个画面 |
- **风格**：精致水彩植物插画（botanical watercolor），每朵花画得像植物图鉴，精细优雅
- **色彩情绪**：自然花卉色（黄/粉/紫/橙/蓝绿），白底干净清新
- **文字层级**：主标题"Mom's Garden"最大（装饰性字体）> 副标题 > 花下名字（手写体）

### 第 3 层｜可变边界层
**可替换的**：
| 维度 | 原始 | 可替换成 |
|---|---|---|
| 主角 | Mom's Garden | Grandma's Garden / Nana's Garden / Dad's Workshop / Grandpa's Garage / Teacher's Classroom |
| 副标题 | "Where Love Grows" | "Planted with Love" / "Blooming with Joy" / "Rooted in Love" |
| 花的种类 | 出生花（Birth Flowers） | 喜欢的花 / 随机花 / 统一花种不同颜色 |
| 装饰 | 蝴蝶 | 蜜蜂、蜻蜓、小鸟、瓢虫 |
| 花的数量 | 6 株（图中） | 1-10 株（根据家庭成员数量灵活调整，1排或2排） |
| 风格 | 水彩植物画 | 简笔线描+淡彩、复古植物图鉴、极简现代 |
| 主题大改 | 花园 | "Dad's Workshop"（每个孩子一个工具）/ "Grandpa's Fishing Buddies"（每个孙子一条鱼）/ "Family Recipe"（每人一个食材） |

**不能换的**：
- "每个家庭成员有专属一个元素+名字"的核心结构（这是购买动机）
- 标题区+元素陈列区的上下两段式构图
- 白底干净感（这是精致礼物感的基础）
- 精致细腻的画风（不能粗糙，这是"拿得出手的礼物"的门槛）

### 第 4 层｜产品适配
- **毛毯**：当前图直接适用。面积大，花朵可以画更多细节，6-10 株都放得下
- **相框/挂画**：花朵缩减到 3-5 株一排，标题字号缩小。非常适合做客厅装饰画
- **衣服**：只做缩略版——标题+"Mom's Garden"+2-3朵花，远看有识别度
- **马克杯**：横向排 3-4 朵花，标题缩小放顶部
- **手提袋**：非常适合，白底花朵天然匹配帆布袋审美

### 第 5 层｜数据验证
- 季节依赖：**低**（母亲节高峰，但生日/乔迁/圣诞全年有）
- IP 依赖：**无**
- 个性化深度：**极高**（名字数量可变 + 花的种类可变 = 每单都是独一无二的）
- 跨产品可行性：**极高**（毛毯/相框/马克杯/袋子/衣服全能做）
- 跨主题可行性：**极高**（花园→工坊→鱼塘→厨房，框架不变只换元素）
- 复用等级：**S 级**——这是目前 5 张图里复用价值最高的规则

## 改款推荐

**推荐方向**：保留"每人一个专属元素+名字"的核心结构，换一个全新主题。

**具体方案**：改成 **Grandma's Garden 奶奶的花园版（水彩花+蝴蝶，配色更柔和复古）**
- "Mom's Garden" → "Grandma's Garden"
- "Where Love Grows" → "Where Memories Bloom"
- 花朵种类不变（出生花概念保留）
- 蝴蝶 → 保留但换成更复古优雅的蝴蝶
- 色调从清新现代 → 偏复古暖调（加一点米色/金色调）
- 花朵画风从精致水彩 → 复古植物图鉴风（更有年代感，适合送奶奶）

**改款理由**：Grandma 市场和 Mom 市场一样大但竞品少，同样的框架换标题+微调色调就能做，几乎零额外成本。
