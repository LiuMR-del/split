> 基于两轮审查报告 + 终审。本文档持久化实施方案,防止会话上下文压缩后丢失步骤。
> 当前进度:全部 6 批次 27 条 ✅ 完成。

## 工作规则
1. 始终用中文回答
2. 阶段式交付:完成一批 -> 自测 -> 报告 diff+验证 -> 等用户确认"通过" -> 下一批。禁止跳阶段
3. 批次内逐项做,每项报告 diff + 验证点
4. 方案已定稿,不改优先级/批次划分。但实施时发现代码事实与方案不符(行号偏移、字段名对不上、遗漏孪生点),立即停下报告,不硬改
5. 改代码前先 Read 相关文件确认现状(行号可能因前序改动漂移),不盲改
6. 每项改动附验证标准的自测结果
7. 多 agent 协同:主 agent 统领,独立文件并行(字段名预先约定)
